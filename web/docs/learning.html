Make it yours

Learning, transcripts & notes

Designate lessons, revisit timestamps and organize study progress.

Release-aware documentation. Guides follow the current development branch. Stable 1.41.0 does not include every recently merged change. Check what is released →

  • Use a transcript
  • Keep timestamped notes
  • Follow progress and study activity
  • Difficulty and review

Learning Mode is optional and off by default. It adds study-oriented organization without treating every song, short or casual video as a lesson. Timestamped notes and transcripts also provide useful tools outside a formal course.

Designate learning content

  1. Enable Learning Mode under Settings → Learning Mode.
  2. Open a video or supported playlist menu and choose Mark as Learning.
  3. Use the learning dashboard to continue designated material and inspect progress.
  4. Remove the designation later if that content should no longer contribute to study activity.

Only explicitly designated videos, supported local media and videos included by designated playlists contribute to the Learning workflow. Removing one designation does not remove another active source, such as membership in a different marked playlist.

Use a transcript

Open the transcript from a video’s Description area where captions are available. Select a language, search the transcript, and tap a line to seek to its timestamp. You can copy text or create a linked note.

Caption data is requested when you open the transcript and is not retained as a disk archive of every video’s captions. The service may not provide a transcript or the language you need. A searchable transcript is not a guarantee of machine translation or perfect caption accuracy.

Keep timestamped notes

Notes link your text to an exact position in supported non-live content. Return to a note when you need to revisit a definition, explanation or passage rather than searching the whole video again.

Playlist note exports support UTF-8 text and CSV. Notes are associated with videos, so deleting a note can affect every playlist that shows the same video. Review that scope before a bulk removal.

Follow progress and study activity

The dashboard can show continue-learning shortcuts, active and completed playlists, recently annotated videos, study time, streaks and a 28-day activity calendar. Supported playlist controls can mark material watched or reset completion.

Choose whether background listening should count toward study activity. Ordinary playback should not become study data merely because Learning Mode is enabled. Incognito pauses supported learning activity recording.

Remote playlist learning, review and note membership operate on loaded/indexed material. If more playlist pages have not been collected, do not assume their videos are already included in a local learning calculation.

Difficulty and review

Optional per-profile Easy, Medium and Hard ratings help organize review sessions and hardest-first ordering. Difficulty ratings do not block playback or completion.

The current implementation supports local or optional synchronized difficulty storage. Select the relevant setting and Device Sync categories rather than assuming every Learning record automatically moves between devices.

Know the data boundaries

Learning-content selections remain device-local. Notes have a separate synchronization control, and supported difficulty ratings have their own configuration. A shared profile name alone does not make all Learning state identical across devices.

Existing videos with learning notes can be designated during an upgrade to preserve earlier work. Keep a supported backup before changing devices or making a large library reorganization. Learning statistics are a personal organizational aid, not an independently verified assessment of skill or study quality.
