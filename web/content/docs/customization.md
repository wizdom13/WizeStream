WizeStream uses a Material 3-oriented interface with configurable navigation, colors, typography and playback controls. Start with readable defaults, then change one area at a time so you can tell which setting produced a result.

## Color and appearance

Built-in appearance choices include Light, Dark, Black, Follow system, manual accent presets and an Eye Comfort warm dark appearance. Dynamic Material You colors are available where supported by Android.

Launcher icon variants and matching TV banners are selected under **Settings → Appearance → App icon**. Android launchers can cache icons or apply their own themed-icon rules, so a change may not appear everywhere immediately.

Theme packs offer a portable appearance configuration. For their format, import workflow and boundaries, see [theme packs](theme-packs.html).

## Shape your navigation

Choose the home sections you actually use and set a preferred main tab. Bottom navigation supports up to five main sections; larger collections can use a scrollable tab layout. Labels can remain visible, appear only for the active destination, or be hidden.

Optional service sections in the drawer and global-search behavior can reduce the number of steps to reach a favorite source. Tablet navigation can use an appropriate rail or bottom arrangement.

## Make lists comfortable

List and grid modes serve different browsing styles. Adjust responsive or fixed tablet columns, portrait/landscape choices, full grid titles and supported text sizing. Title, channel, metadata and comment text can be configured independently where the relevant controls are available.

Before reporting a truncated title or inaccessible menu, check the display mode, font scaling, orientation and whether the issue appears with the default appearance. Those details make a UI report more useful without requiring a private database export.

## Player and notification controls

Playback gestures, bottom player controls, notification actions, artwork and lock-screen thumbnails can be customized. Seek bars and feed refresh indicators provide their supported visual styles.

TV shortcuts and D-pad behavior are distinct from phone gestures. Configure the controls you use rather than assuming a touch gesture will translate to a remote. The [device guide](devices.html) explains the supported contexts.

## Accessibility and permissions

Android caption styling, text size, visible focus and descriptive native controls remain important when choosing a theme. A custom skin should not replace a usable touch target with a decorative image.

The home-screen playback widget offers previous, play/pause and next. With no active player it opens WizeStream. It does not use background polling or store listening titles as a separate widget history.

Grant optional permissions only for the feature you intend to use: notifications, popup overlays, local media access, or scanning a device-pairing code, for example. Appearance customization does not require a platform account.

## Find or reset a setting

Use settings search when a guide names a feature but the menu layout differs in your installed build. Some controls arrive after a stable release, and phone/tablet layouts can show the same preference in different arrangements.

Export a theme or app backup before a substantial change. Theme restoration restores appearance; it does not replace a complete library backup. Use the specific reset controls for the setting or feature you want to restore.
