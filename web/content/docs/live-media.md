Live TV, internet radio and local media extend WizeStream beyond on-demand platform videos. They use different sources and storage models, so their availability, favorites and backup behavior should be understood separately.

## Discover internet radio

Open **Live Radio** from the drawer to browse Radio Browser stations. Search by station name and narrow the directory by country, language or genre. Save favorites or add a custom supported HTTPS audio/HLS stream.

The miniplayer can show a station logo and details with playback and queue actions. Filters are remembered per profile and can synchronize when the Device Sync Filters category is enabled.

Station-supplied song metadata may be recorded in profile history when history recording is enabled. Selecting such an entry tunes the station again; it does not replay the song as it sounded at that earlier time. Incognito and history controls still apply.

## Browse Live TV

1. Open **Live TV** in the navigation drawer.
2. Select **Browse channels**.
3. Choose the default IPTV-org source or optional Free-TV source.
4. Find a country, load its channels, and select a supported stream.
5. Save favorites or narrow the list with search and group filters.

The directories are community-maintained collections of external streams. Country lists do not require location permission. Availability can change, be region-limited, or depend on the broadcaster. The presence of a directory entry is not a WizeStream guarantee that it will work everywhere.

## Import your own TV source

Import a local M3U file, add a supported HTTPS playlist URL, or use a custom supported channel/HLS URL. Only supported HTTPS entries are imported from the supplied directories.

Current limits include a 4 MiB import, ten playlists and 5,000 cached stream URLs per profile. Large or unsupported input is not an unlimited channel database.

Playlists and favorites are stored separately per profile. Keep the original M3U file and source URLs: do not assume every Live TV record is included in a portable app backup.

## Refresh and choose another stream

Saved country lists can appear from cache. When Live TV opens or resumes, lists older than 24 hours refresh automatically, retaining cached entries if refresh fails. Playlist management also offers manual refresh.

Directory duplicates can be combined by channel within a country. Long-press a channel and use **Choose stream** when alternative URLs exist. Try a listed alternative rather than repeatedly restarting the same unavailable endpoint.

Playback uses WizeStream’s existing player with supported fullscreen and TV remote controls. Service-specific social features such as comments are not automatically available for a plain IPTV stream.

## Browse media on your device

**Local Media** reads audio and video files to which Android has granted the app access. Browse folders, use search and filters, inspect metadata and thumbnails, and rescan when your storage changes. Exclusions help keep unwanted folders out of the view.

Local files can use supported main, background and popup playback. A file must still be accessible at its saved location; moving it, revoking folder access or removing external storage can make a library entry unavailable.

## Privacy and storage boundaries

Directory browsing contacts its directory provider; starting a station or channel contacts the chosen stream source. Local playback does not turn a local file into a cloud upload. A stream address may still contain credentials supplied by its owner, so keep private playlist URLs out of public reports.

Back up irreplaceable local media as files. Database exports and Device Sync metadata do not transfer the audio or video itself.
