Before opening an issue

Make the problem
easy to understand.

  1. Check the installed version and whether you are using stable, nightly or a PR/debug build.
  2. Identify the selected service, optional instance/proxy and a public example URL.
  3. Write the exact action, expected result and observed result.
  4. Include Android/device details and relevant playback or filter state.
  5. Review any log before sharing it. Remove cookies, credentials, private URLs and personal data.

Do not upload a full private database just to demonstrate a missing item. For sensitive material, ask the maintainer for an appropriate private route before posting it.
