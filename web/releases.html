Stable releases.
Recent development.

The stable download and the development handbook do not always describe the same set of changes.

Merged after 1.41.0

Not in the listed stable APK yet.

  • Independent 360° playback and A–B repeat enable switches, both off by default.
  • Further live DVR protection, bounded preparation recovery and compatible buffered DASH URL refresh.
  • Optional full-video sponsorship disclosures and opt-in SponsorBlock contribution tools.
  • FreeTube subscription and playlist import/export.

The underlying 360° capability is already listed in 1.41.0. Its newer enable/disable setting is a separate change. Read the installed build’s release notes rather than assuming all handbook features are present.
