A few useful details

Install once.
Update consistently.

WizeStream keeps the historical package ID org.wisso.newpipematerial so existing users can update after its rename. Official NewPipe has a different app ID and can coexist.

Keep the same source

Use the same installation/update source whenever possible. A signature mismatch should be investigated before removing an app that contains your local library.

Move your data deliberately

Export an original backup before importing from NewPipe or another supported format. Verify subscriptions and playlists before discarding the source file.

Know the permission

Android’s permission to install an APK belongs to the browser or file manager handling it. Popup, notifications and local-media access are separate feature permissions.
