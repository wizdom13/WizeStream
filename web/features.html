Streaming & discovery

Browse supported public sources without a platform login.

Read the guide
  • YouTube with Music and Shorts destinations, plus SoundCloud, PeerTube, Bandcamp and media.ccc.de.
  • Integrated Bilibili, Niconico, BitChute and Rumble; experimental Odysee support.
  • Service-specific search, channel tabs, supported public posts and contextual collection search.
  • Optional local recommendations, saved searches, and local video/channel/content filtering.

Playback & audio

Keep useful controls close to the media.

Read the guide
  • Main video, background, Listen, popup and optional native Android PiP.
  • Captions, searchable transcripts, chapters, audio-track selection and per-channel preferences.
  • Pinch zoom, fullscreen gestures, touch lock, session caption timing and non-live A–B repeat.
  • 360° projection controls, a 10-band equalizer, visualizers and optional normalization/compression.

Local library

Build an organized collection on your device.

Read the guide
  • Subscriptions, channel groups, What’s New filters and selected-channel notifications.
  • Local playlists, remote bookmarks, categories, separators and supported bulk editing.
  • Rule-based smart playlists over locally indexed media.
  • Separate supported libraries by profile; pause supported activity recording with Incognito.

Downloads & offline

Choose the files and schedule that fit your device.

Read the guide
  • Video, audio and caption downloads, plus supported full-video companion caption files.
  • Playlist/queue batches, optional automatic channel downloads and resumable transfer controls.
  • Daily download windows with optional charging and unmetered-network constraints.
  • Optional retention for tracked automatic downloads, previews and permanent-file protection.

Profiles, backups & sync

Move supported records intentionally.

Read the guide
  • Encrypted peer-to-peer Device Sync after one-time QR pairing on a reachable local network.
  • Supported profile identities, subscriptions, playlists, history, progress and selected settings.
  • Manual backups, optional scheduled local backups, and compatible migration formats.
  • Download metadata can sync; actual video/audio files do not.

Learning & notes

Keep lessons distinct from casual watching.

Read the guide
  • Timestamped notes and transcript search for supported content.
  • Optional Learning Mode for explicitly designated videos and playlists.
  • Learning dashboard, supported progress controls, study activity and review shortcuts.
  • Optional per-profile difficulty ratings, with local or supported synchronized storage.

Live and local media

Use sources beyond an on-demand platform feed.

Read the guide
  • Worldwide Radio Browser discovery with station filters, favorites and supported custom streams.
  • Live TV country directories from IPTV-org or Free-TV, plus M3U/HTTPS imports.
  • Per-profile TV playlists/favorites, cached lists and available alternative streams.
  • Local audio/video browser with folders, search, filters, exclusions and rescans.

Devices & receivers

Use the interface that matches the situation.

Read the guide
  • Phone, tablet, landscape and Android TV layouts with supported D-pad shortcuts.
  • Audio browsing, search and resume through Android Auto.
  • FCast and Chromecast-compatible casting for supported receivers and stream formats.
  • Optional HTTPS yt-fifo/Snapcast home-audio handoff.

Appearance & accessibility

Personalize without executable theme plugins.

Read the guide
  • Material 3-oriented surfaces, dynamic or manual colors, and light/dark/black/system choices.
  • Configurable home navigation, text sizing, list/grid layouts and tablet columns.
  • Previewable JSON theme packs with supported palette, glass and native listening layouts.
  • Native controls and accessibility semantics remain important when using a custom skin.
