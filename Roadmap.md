### Todo Roadmap

### High-priority features

**1. Add TV casting**
Most visible user-facing upgrade for a video app.

**2. Better update experience**
Improve the existing update checks with a clearer “new version available” UI, changelog preview, APK download progress, and install prompt flow.

**3. Diagnostics and stability reporting**
Very important now that extractor warnings are being hidden in release builds. Users need a clean way to report issues.

**4. Android Auto support**
Useful, but more specialized and mostly audio-focused.

### Good Material-focused improvements

**5. More Material You polish**
Improve dynamic color tuning, settings pages, empty states, error screens, and icon consistency.

**6. Better tablet/foldable layout**
Improve large-screen support with better two-pane layouts for subscriptions, search, details, and playlists.

**7. Improved home screen customization**
Let users choose which sections appear, such as Trending, Subscriptions, Bookmarks, Recommended Lives, Downloads, History, and service-specific kiosks.

**8. Backup/restore polish**
Make import/export easier, safer, and more visible, especially for subscriptions, settings, playlists, and SponsorBlock settings.

### Worth doing later

**9. SponsorBlock polish**
Improve segment settings, category presets, skip overlays, and optional local stats.

**10. Playback quality profiles**
Add defaults such as “Wi-Fi: best up to 1080p,” “Mobile data: 480p,” and “Background: audio only.”

**11. Download queue improvements**
Improve the download UI, retry failed downloads, show better format labels, and display clearer per-service download capability messages.

**12. Better onboarding**
Add first-run setup for theme, update channel, SponsorBlock, dislikes, default playback quality, enabled services, and diagnostics preferences.
